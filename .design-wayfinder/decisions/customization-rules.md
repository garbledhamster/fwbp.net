# Answer

Pick the product first. Start with both design choices at None. On a T-shirt or sweatshirt, either design can go on the back or chest, and the same design can appear in both places. Keep Secondary in memory while previewing a mug, hat, or sticker, which uses only Primary. Preview a blank item and require at least one print on the current product to add it to the cart.
